## 🚀 About

This repository contains a Python desktop application for **audio conversion, filtering, stereo processing and mastering-style export workflows**. It uses CustomTkinter for the interface, `pydub` for audio manipulation and FFmpeg/FFprobe as the underlying media engine.

The program can process individual files or entire folders, export WAV/MP3 variants and apply optional DSP steps such as frequency filtering, stereo micro-shift, low-level analog-style noise texture and output limiting.

It is designed for users searching for a **WAV to MP3 converter**, **Python audio mastering GUI**, **FFmpeg desktop converter**, **pydub audio processor**, **batch audio converter** or a lightweight desktop DSP utility.

## ✨ Features

| Feature | Description |
|---|---|
| 🎵 WAV / MP3 input | Load individual audio files |

## 📋 Requirements

- Python 3.x
- FFmpeg
- FFprobe

Install Python dependencies:

```bash
pip install customtkinter pydub
```

Make sure `ffmpeg` and `ffprobe` are available in your system `PATH`.

## 📦 Installation
